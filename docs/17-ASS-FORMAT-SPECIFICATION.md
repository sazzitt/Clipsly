# Clipsly Phase 18 — ASS Subtitle Format Specification

## 1. Specification Overview

This document specifies the exact structure, tags, timing conventions, and character escaping rules for **Advanced SubStation Alpha (ASS v4.00+)** subtitle files generated by Clipsly.

All generated `.ass` files are tailored for high-resolution 9:16 vertical video renders ($1080 \times 1920$) and are consumed by:
1. **FFmpeg `libass` Filter:** For burning hardcoded subtitles into exported MP4 files.
2. **Clipsly Studio UI Preview:** For client-side rendering and interactive caption fine-tuning.

---

## 2. File Structure

An ASS file generated by Clipsly consists of three mandatory sections:
1. `[Script Info]` — Metadata and video resolution target.
2. `[V4+ Styles]` — Typographic definitions, color definitions, and margins.
3. `[Events]` — Word-synchronized dialogue events with karaoke tags.

---

## 3. Section 1: `[Script Info]`

The header establishes canvas dimensions, wrap rules, and collision handling.

```ini
[Script Info]
; Script generated by Clipsly Subtitle Engine v18.0
; Local-First AI Video Clipper (ASUS TUF A15 / RTX 3050)
Title: Clipsly Karaoke Captions
ScriptType: v4.00+
WrapStyle: 0
ScaledBorderAndShadow: yes
YCbCr Matrix: TV.709
PlayResX: 1080
PlayResY: 1920
```

### Header Fields:
- **`ScriptType: v4.00+`**: Specifies modern Advanced SubStation Alpha format.
- **`WrapStyle: 0`**: Smart line wrapping. Lines wrap evenly when exceeding width, or wrap at explicit `\N` tags.
- **`ScaledBorderAndShadow: yes`**: Scales border thickness and shadow depth proportionally to `PlayResY` ($1920\text{px}$). Ensures identical visual weight across different display resolutions.
- **`PlayResX: 1080` & `PlayResY: 1920`**: Locks coordinate system to exact 9:16 vertical resolution. All fonts, margins, outlines, and positions are specified in pixels against this canvas.

---

## 4. Section 2: `[V4+ Styles]`

Defines the reusable typography presets. Each style is a comma-separated record conforming to the format header.

### 4.1 Format Definition Line
```ini
[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
```

### 4.2 Field Definitions & Constraints

| Field | Type | Description | Clipsly 1080x1920 Standard |
|---|---|---|---|
| **Name** | String | Identifier used by Dialogue events | `Default`, `KaraokeActive`, `TopTitle` |
| **Fontname** | String | System font family | `Montserrat`, `Inter`, `Impact`, `Arial` |
| **Fontsize** | Integer | Point size scaled to 1920px canvas | `72` - `110` (equivalent to 24-36pt on 720p) |
| **PrimaryColour** | Hex (`&HAABBGGRR`) | Base text fill color (unspoken / post-karaoke) | `&H00FFFFFF` (Solid White) |
| **SecondaryColour** | Hex (`&HAABBGGRR`) | Pre-karaoke fill color (active karaoke target) | `&H0000D7FF` (Gold / Amber) |
| **OutlineColour** | Hex (`&HAABBGGRR`) | Stroke / border color | `&H00000000` (Solid Black) |
| **BackColour** | Hex (`&HAABBGGRR`) | Drop shadow or bounding box color | `&H80000000` (50% Semi-transparent black) |
| **Bold** | Boolean (`-1` / `0`) | `-1` = True, `0` = False | `-1` (Short-form captions require high weight) |
| **Italic** | Boolean (`-1` / `0`) | `-1` = True, `0` = False | `0` |
| **Underline** | Boolean (`-1` / `0`) | `-1` = True, `0` = False | `0` |
| **StrikeOut** | Boolean (`-1` / `0`) | `-1` = True, `0` = False | `0` |
| **ScaleX** | Percentage | Horizontal font stretch (%) | `100` |
| **ScaleY** | Percentage | Vertical font stretch (%) | `100` |
| **Spacing** | Integer | Additional inter-letter spacing in pixels | `1` to `3` |
| **Angle** | Float | Z-axis rotation angle in degrees | `0.0` |
| **BorderStyle** | Integer | `1` = Outline + Drop Shadow; `3` = Opaque Bounding Box | `1` (Default) or `3` (Podcast Box) |
| **Outline** | Float | Outline thickness in pixels | `6.0` to `10.0` (Ensures contrast against busy video) |
| **Shadow** | Float | Drop shadow depth in pixels | `2.0` to `4.0` |
| **Alignment** | Integer | Numpad position: `2`=Bottom Center, `5`=Center, `8`=Top Center | `2` (Bottom Center standard) |
| **MarginL** | Integer | Left margin bound (px) | `100` |
| **MarginR** | Integer | Right margin bound (px) | `100` |
| **MarginV** | Integer | Vertical margin from anchor edge (px) | `380` (Bottom) / `0` (Center) / `280` (Top) |
| **Encoding** | Integer | Font character set (`1` = Default ANSI/Unicode) | `1` |

### 4.3 ASS Color Notation (`&HAABBGGRR`)
ASS colors use reverse hexadecimal order with alpha channel first:
$$\&H\mathbf{AA}\mathbf{BB}\mathbf{GG}\mathbf{RR}$$

- $\mathbf{AA}$: Alpha / Opacity ($00 = \text{Fully Opaque}$, $FF = \text{Fully Transparent}$).
- $\mathbf{BB}$: Blue component ($00 \dots FF$).
- $\mathbf{GG}$: Green component ($00 \dots FF$).
- $\mathbf{RR}$: Red component ($00 \dots FF$).

#### Conversion Formula from Hex (`#RRGGBB`):
```python
def hex_to_ass_color(hex_color: str, alpha: int = 0) -> str:
    """Converts #RRGGBB or #RRGGBBAA to ASS &HAABBGGRR string."""
    clean = hex_color.lstrip("#")
    if len(clean) == 6:
        r, g, b = clean[0:2], clean[2:4], clean[4:6]
        a = f"{alpha:02X}"
    elif len(clean) == 8:
        r, g, b, a = clean[0:2], clean[2:4], clean[4:6], clean[6:8]
    else:
        raise ValueError(f"Invalid hex color format: {hex_color}")
    return f"&H{a}{b}{g}{r}".upper()
```

## 5. Section 3: `[Events]`

Contains dialogue and karaoke animation lines.

### 5.1 Format Definition Line
```ini
[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
```

### 5.2 Timestamp Formatting
Timestamps must follow the strict `H:MM:SS.cs` format (centisecond resolution = 10ms intervals):
- `H`: Hour (single or multi-digit, e.g. `0`, `1`).
- `MM`: Minutes ($00 \dots 59$).
- `SS`: Seconds ($00 \dots 59$).
- `cs`: Centiseconds ($00 \dots 99$).

```python
def format_ass_timestamp(milliseconds: int) -> str:
    """Formats milliseconds integer into H:MM:SS.cs timestamp."""
    total_seconds = milliseconds / 1000.0
    hours = int(total_seconds // 3600)
    minutes = int((total_seconds % 3600) // 60)
    seconds = int(total_seconds % 60)
    centiseconds = int(round((total_seconds - int(total_seconds)) * 100))
    if centiseconds >= 100:
        seconds += 1
        centiseconds = 0
    return f"{hours}:{minutes:02d}:{seconds:02d}.{centiseconds:02d}"
```

## 6. Karaoke Highlighting Tags

Clipsly generates word-by-word karaoke using standard ASS timing tags:

### 6.1 Supported Karaoke Tags

| Tag | Name | Behavior | Usage in Clipsly |
|---|---|---|---|
| `\k<duration_cs>` | Instant Karaoke | The text switches from `SecondaryColour` to `PrimaryColour` instantly once the word duration elapses. | Minimal & Bold Presets |
| `\kf<duration_cs>` or `\K<duration_cs>` | Smooth Sweep Karaoke | The fill sweeps smoothly left-to-right across the syllables during `duration_cs`. | Modern & Karaoke Amber |
| `{\1c&H...&}` | Color Override | Forces an explicit primary color for highlighted words. | Emphasized Hook Words |
| `{\fscx115\fscy115}` | Scale Pop | Bumps word scale by 15% during speech to create bouncy pop effect. | Viral / Hormozi Style |

### 6.2 Karaoke Duration Calculation
The duration tag integer $\tau$ is expressed in **centiseconds** (1 centisecond = $10\text{ms}$):
$$\tau = \max\left(1, \operatorname{round}\left(\frac{\text{word.end\_ms} - \text{word.start\_ms}}{10}\right)\right)$$

### 6.3 Inter-Word Lead-in & Gaps
When silence exists between words within a single caption line, the gap duration is prepended to the subsequent word's tag or encoded as an empty tag `{\k<gap_cs>}` to prevent premature color illumination.

## 7. Character Escaping & Unicode Sanitization

Special characters in dialogue text must be sanitized before compiling ASS events to prevent syntax breakage in `libass`:

1. **Curly Braces (`{` and `}`):**
   - In ASS format, `{` and `}` are reserved as control code delimiters for override tags (e.g., `{\kf30}`).
   - If raw spoken dialogue contains literal `{` or `}` characters, they must be converted to full-width unicode braces (`｛` / `｝`) or replaced with standard parentheses `(` and `)`. Raw unescaped curly braces must never leak into dialogue text.
2. **Backslashes (`\`):**
   - In ASS format, backslashes introduce control sequences (`\N`, `\h`, `\k`, `\1c`).
   - Literal backslashes in speech text must be sanitized by converting to forward slashes `/` or escaped as double backslashes `\\`.
3. **Commas in Dialogue:**
   - In ASS `[Events]` lines, fields are comma-delimited: `Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text`.
   - Because `Text` is the 10th and final field in the record, commas occurring naturally in dialogue text are strictly safe and preserved as-is. `libass` treats all characters after the 9th comma as the Text payload.
4. **Line Breaks:**
   - Soft/hard line breaks must use `\N` (uppercase) or `\n` (lowercase). Clipsly uses `\N` exclusively.
   - Non-breaking spaces use `\h`.
5. **Encoding & Unicode:**
   - Files are written in strict **UTF-8 without Byte Order Mark (BOM)**.
   - Preserves emojis, multi-lingual scripts (CJK, Arabic, Cyrillic), accents, and smart typography (`"`, `'`, `—`).

### Safe Text Sanitization Reference Implementation:
```python
def sanitize_ass_text(text: str) -> str:
    """Sanitizes raw transcript text for safe injection into ASS dialogue lines."""
    # Convert literal backslashes to avoid accidental tag escapes
    sanitized = text.replace("\\", "/")
    # Replace literal curly braces to prevent syntax collision with ASS override tags
    sanitized = sanitized.replace("{", "｛").replace("}", "｝")
    # Normalize carriage returns and newlines to ASS explicit line breaks
    sanitized = sanitized.replace("\r\n", r"\N").replace("\n", r"\N")
    return sanitized.strip()
```
